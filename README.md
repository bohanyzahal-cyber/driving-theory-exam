# מערכת מבחני תאוריה דיגיטלית

מערכת מבחני תאוריה ממוחשבים לרישוי צה"ל: בחינה חיצונית מפוקחת על-ידי בוחן, תרגול לתלמידים, וניהול כיתות למורים. כוללת דשבורדים למפקדים, שכבת BI חיזויית, ודו"חות שיתופיים.

> **מסמך זה הוא נקודת הכניסה.** אם אתה מקבל אחריות על המערכת — קרא אותו במלואו, ואז את [`docs/OPERATIONS.md`](docs/OPERATIONS.md) לפני שאתה נוגע בפרודקשן.

## 2. ארכיטקטורה בגדול

אין שרת אפליקציה ואין בסיס נתונים קלאסי. שלוש פלטפורמות מתארחות בנפרד:

```
┌─────────────────────────────────────────────────────────┐
│  GitHub Pages   — כל דפי ה-HTML (הלקוחות)               │
│  repo: driving-theory-exam, branch master               │
│  push → פריסה אוטומטית                                   │
└───────────────────────┬─────────────────────────────────┘
                        │  fetch (GET/POST) עם origin
                        ▼
┌─────────────────────────────────────────────────────────┐
│  Google Apps Script — ה-API כולו (external_exam_...js)  │
│  67 handlers, נקודת קצה אחת /exec                        │
│  פריסה ידנית: הדבקה בעורך → New version → Deploy         │
└───────┬──────────────────────────┬──────────────────────┘
        │                          │
        ▼                          ▼
┌────────────────────┐   ┌──────────────────────────────┐
│ Google Sheets      │   │ Google Drive (תיקייה פרטית)  │
│ 14 גיליונות = ה-DB │   │ בנק השאלות, JSON לכל שפה     │
└────────────────────┘   └──────────────────────────────┘

┌─────────────────────────────────────────────────────────┐
│  Cloudflare Workers — שירותי צד                          │
│  • קישורי דו"חות (KV)  • TTS עברית  • פרוקסי תמונות      │
│  פריסה: wrangler (לא דרך הדשבורד — ראה OPERATIONS)       │
└─────────────────────────────────────────────────────────┘
```

**המשמעות התפעולית:** `git push` מעדכן **רק** את הלקוחות. שינוי ב-Apps Script או ב-Workers לא מגיע לאוויר עד פעולה ידנית נפרדת. זו הטעות הנפוצה ביותר במערכת הזו.

## 4. זרימת הבחינה (הליבה)

```
בוחן פותח סשן  →  קוד בן 6 תווים, תקף 8 שעות
       ↓
נבחן מקליד קוד  →  getSessionInfo  →  ממלא פרטים  →  registerExaminee
       ↓                                                    ↓
       └──────── polling כל 5 שניות: checkApproval ──── שורה בגיליון "ממתינים"
                              ↓
בוחן מאשר (+ הארכת זמן, + שמע)  →  הנבחן עובר למסך הנחיות
                              ↓
נבחן לוחץ "התחל"  →  getExamQuestions (30 שאלות לפי blueprint)
                              ↓
              ★ מכאן המבחן רץ מקומית לחלוטין — אין תלות ברשת ★
                              ↓
הגשה  →  submitResult (POST)  →  ניקוד בצד השרת  →  שורה ב"תוצאות"
```

**שתי נקודות הרשת היחידות** הן תחילת המבחן וההגשה. נפילת אינטרנט באמצע לא מפילה מבחן.

**הניקוד תמיד בצד השרת.** הלקוח לא נאמן — הוא שולח את מזהי השאלות ואת פרמוטציית הערבוב, והשרת גוזר את התשובה הנכונה ממפתח התשובות שלו.

## 5. מפת קבצים

### הליבה — כאן נמצאת רוב העבודה

| קובץ | גודל | מה זה |
|---|---|---|
| `external_exam_apps_script.js` | ~356KB | **כל ה-API.** 67 handlers, נתב GET/POST יחיד |
| `examiner.html` | ~468KB | אפליקציית הבוחן, self-contained |
| `examinee.html` | ~252KB | אפליקציית הנבחן, self-contained |
| `teacher.html` | ~100KB | אפליקציית המורה |
| `student.html` | ~112KB | אפליקציית התלמיד |

כל דף הוא קובץ בודד — HTML+CSS+JS ביחד, ללא build step וללא תלויות חיצוניות. כל ה-JS עטוף בתבנית `(function() { 'use strict'; ... })()`.

### תשתית

| נתיב | מה זה |
|---|---|
| `cloudflare-workers/` | worker קישורי הדו"חות + `wrangler.toml` |
| `deployment/` | סקריפטי התקנה לכיתות + כלי יצירת בנק שאלות |
| `sw-*.js`, `manifest-*.json`, `icon-*.png` | תשתית PWA |
| `signs_data.js` | ~5MB — נתוני תמרורים ללומדה |

## 6. איפה הנתונים

| מה | איפה | הערה |
|---|---|---|
| בוחנים, נבחנים, סשנים, תוצאות, כיתות, תרגול | Google Sheets, 14 גיליונות | ראה `docs/DATA_MODEL.md` |
| בנק השאלות (~12,566 שאלות × 7 שפות) | **תיקיית Drive פרטית** | לא במאגר! JSON לכל שפה |
| קישורי דו"חות | Cloudflare KV | קבועים (ללא TTL) |
| סיסמאות/טוקנים | Google Sheets + ScriptProperties | ראה §7 |

**⚠️ בנק השאלות אינו במאגר הזה.** מיקום התיקייה מוגדר ב-ScriptProperty בשם `QUESTIONS_DRIVE_FOLDER_ID`. עריכת JSON מקומי **לא משנה כלום** עד להעלאה ל-Drive וניקוי מטמון. זו מלכודת חוזרת — פרטים ב-`docs/KNOWN_ISSUES.md`.

## 7. סודות והרשאות

**אין סודות במאגר, וכך זה צריך להישאר — שני המאגרים ציבוריים.**

| סוד | איפה הוא חי |
|---|---|
| `QUESTIONS_DRIVE_FOLDER_ID` | ScriptProperties של Apps Script |
| `UPLOAD_SECRET` | Cloudflare Worker secret |
| סיסמאות בוחנים/מורים | גיליון `בוחנים` / `מורים` |
| טוקני התחברות | נוצרים בשרת, עם תוקף |

מי שמקבל את המערכת צריך גישה ל: חשבון Google של הגיליון וה-Apps Script, תיקיית ה-Drive של בנק השאלות, חשבון Cloudflare, וחשבון GitHub `bohanyzahal-cyber`.

**שכבות אבטחה קיימות:** allowlist של `origin` (רך, בר-עקיפה), טוקן בוחן/מורה עם תוקף, טוקן נבחן לכל הרשמה, הגבלת קצב לכל פעולה, ניקוד בצד השרת בלבד, ואימות שהשאלות שהוגשו הן אלה שנמסרו.
