## 1. מה כן בגיט

### מאגר א׳ — `driving-test` (שורש, ציבורי)

עוקב אחרי **3 קבצים בלבד**:

| קובץ | גודל | מה זה |
|---|---|---|
| `index.html` | | אתר התרגול החופשי |
| `questions.js` | 8.8MB | בנק שאלות **ציבורי** לאתר החופשי |
| `simple_mode.html` | | מצב פשוט |

> שים לב: `questions.js` **ציבורי כאן במכוון** (אתר תרגול חופשי), אבל **מוחרג** במאגר מערכת הבחינות. שני שימושים שונים לאותו סוג נתון.

### מאגר ב׳ — `driving-theory-exam` (תיקיית `standalone_exam`, ציבורי, ענף `master`)

כאן חיה מערכת הבחינות: כל דפי ה-HTML, `external_exam_apps_script.js`, תשתית PWA, `cloudflare-workers/`, `deployment/` (סקריפטים בלבד), וכל התיעוד ב-`docs/`.

**`standalone_exam` הוא מאגר גיט מקונן** — `git add` ממאגר השורש לא יוסיף ממנו כלום. צריך `cd standalone_exam` תחילה.
