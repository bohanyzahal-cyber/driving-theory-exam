## 1. עקרונות

- **כל טקסט שאלה סטטי; השרת מחזיק רק אינדקס מזהים ומפתח תשובות.** אין Drive, אין מאגרים במטמון, אין חימום, אין lease.
- **מכשיר אחד = לכל היותר בקשה חיה אחת לכל לולאה; הסקר של הנבחנים לא מגיע ל-Apps Script אלא ל-Worker שמאחד אותו** (בקשה אחת לסשן כל 3 שנ' במקום אחת לנבחן כל 5 שנ').
- **אף קריאה מלאה של גיליון שגדל לנצח בנתיב חם:** ארכוב לילי של `מבחנים` ו-`תוצאות` כמו `ממתינים`; קוראי היסטוריה מאחדים חי+ארכיון בעמודות הנחוצות בלבד.
- **כתיבת סטטוס אחת:** כל שינוי סטטוס ב-`ממתינים` עובר דרך פונקציה אחת שגם מבטלת את ה-snapshot.
- **הלקוח מניח שהשרת עלול לענות 404/HTML גם כשהכתיבה הצליחה** (ה-302 נשלח אחרי ההרצה). תשובה כזו = "לא ידוע", לעולם לא "נכשל", ולעולם לא "גרסה חדשה" ולא "טוקן פג".
- **פריסה = בדיקות + אימות חי + רישום; אף פעם לא ב-48 השעות שלפני בחינה ולא בבוקרה.**
- **מבנה:** שרת מפוצל למודולים ב-`server/src/` ומורכב לקובץ אחד להדבקה (`external_exam_apps_script.js` = קובץ **מיוצר**); לקוח עם שכבת תקשורת אחת משותפת (`shared/transport.js`); בדיקות = שערי רגרסיה.

## 3. הארכיטקטורה

### 3.1 בנק השאלות הסטטי

- **מקור אמת:** `deployment/generated/questions_<lang>.json` (7 קבצים, == Drive, == שרשרת המקור). תיקון נתונים: id 120 עם `imageUrl:"realistic_visual_road_demo"` → ריק (35 שורות, 7 שפות).
- **בנייה:** `node tools/build_bank.js` →
  - `bank/<lang>.json`: מערך ממוין לפי id, **id ייחודי**: `{id, t, a:[…], i:'TQ_PIC_….jpg'|''}` + `v:{<license>:{t?,a?}}` רק ל-5+4 המזהים בעברית שנוסחם שונה בין שורות דרגה (1276, 829, 124, 126, 621…). בלי `ci`, בלי קטגוריה (השרת מחזיר את הנושא לכל שאלה שנבחרה). 446–696KB, gzip 140–188KB לשפה. **מחויב לריפו הציבורי.**
  - `bank/manifest.json`: `{build, langs:{<lang>:{sha, count, bytes}}}` — ה-sha משמש ל-cache-busting (`bank/he.json?v=<sha>`).
  - `deployment/question_index.json` → מוזרק בבנייה לקובץ השרת כ-`var QUESTION_INDEX`: לכל id: `{c:{<license>:<topic>}, l:<bitmask שפות זמינות>, img:0|1}`. ה-topic הוא אחד מחמשת נושאי ה-blueprint אחרי `classifyCategoryServer`; הדרגות לפי `filterByLicenseServer` (כולל 'זכות קדימה' לכל הדרגות וכלל דרגה '1'). איחוד על פני השפות + מסכת זמינות (ru בלי 907; en +6 ו-14 ב-C1). **שער:** לכל שפה×דרגה, סט המזהים מהאינדקס == סט המזהים של `filterByLicenseServer`+dedupe על ה-JSON.
- **לקוח (`BankStore`, משותף לנבחן/תלמיד/בוחן/find_image):** `load(lang)` (fetch עם `?v=sha`, Cache API דרך ה-SW, זיכרון), `get(id, lang, license)` (מיישם variant). הנבחן טוען את שפת הבחינה + עברית בזמן ההרשמה (הרבה לפני "התחל"), ושאר השפות ברקע בזמן ההמתנה. החלפת שפה = מקומית.

### 3.2 התחלת מבחן = קריאה אחת: `startExam` (POST, טוקן נבחן)

1. אימות טוקן ומצב (`approved`/`in_exam`) מתוך snapshot הסשן.
2. אידמפוטנטיות: `qmap_<session>_<id>` ב-CacheService (3 שעות) — ניסיון חוזר מקבל בדיוק את אותה מפה. אם אין במטמון: סריקת עמודות A–B של `מבחנים` (חי) ואם נמצאה שורה `in_exam` של אותו ניסיון — קריאת עמודה C של השורה ההיא.
3. בחירת 30 מזהים מה-`QUESTION_INDEX` לפי ה-blueprint של הדרגה ושפת הבחינה; לכל שאלה `shuffleOrder` (אקראי בשרת), `correctShuffledIdx` ממפתח שפת הרישום, נושא.
4. `appendRow` ל-`מבחנים` (אותן 6 עמודות — המפה JSON כמו היום, כדי שהניקוד לא ישתנה).
5. `approved → in_exam` + זמן התחלה, דרך כותב הסטטוס היחיד.
6. תשובה: `{status:'ok', build, examMinutes, extraMinutes, audioMode, questions:[{id, order:[…], topic}]}`.
- **עלות:** 0 Drive, 0 מאגרים; 1 snapshot (0–2 RT), 1 append, 2 setValue, flush. יעד ≤ 3 שנ' כולל הזנקה.
- מוסרים: `getExamQuestions`, `registerExamQuestions` (4 ניסיונות ללא אידמפוטנטיות), `markExamStarted` (נשאר רק כ-no-op אידמפוטנטי ללקוח ישן במשך גרסה אחת), `issued_qs_*`, `getQuestionsByIds` עם טקסטים.
- **תרגול (`startPractice`, GET, student/standalone):** אותה בחירה; מחזיר `{id, topic, ci:{he:…,ru:…,…}}` (ci מקודד XOR כמו היום, לכל 7 השפות) → החלפת שפה בתרגול מקומית לגמרי. `mode=category|exam|ids` (ids = חזרה מרווחת: הלקוח שולח את המזהים שלו, עד 50).

### 3.3 הגשה: `submitResult` (POST) — הלקוח שולח את מה שהוצג, השרת מנקד

- `answers[i] = {qIdx, selected, langAtAnswer, q:<טקסט השאלה כפי שהוצג>, a:[<4 התשובות בסדר שהוצג>]}`. הטקסטים משמשים **רק** לתעודה (`פירוט שגויות`, וואטסאפ); הניקוד — אך ורק ממפת `מבחנים` + `ANSWER_KEY_BY_LANG` לפי `langAtAnswer` (ללא שינוי). מוסר: `questionMetaForLanguage`/הבנקים מהשרת.
- **תיקוני נכונות (נספח ה'):** S1 מפה ריקה/קצרה (<25) → סירוב ברישום וסירוב לנקד; S2 `selected` null/''/לא-מספר/שלילי = לא נענתה; S4 ערך מהלקוח ל-`correctShuffledIdx` לא נאמן יותר (ערך לא מאומת = לא מאומת, ולעולם לא "עבר מאומת"); S7 סינון `בוטל` ב-correctToPass/commanderCorrectResult/submitWrongAnswersBulk; S8 סף תרגול = `ceil(total*0.86)` בשני הצדדים.
- **קריאות:** טוקן (snapshot) · מפה מהמטמון (נפילה: סריקת A–B + שורה) · `תוצאות`: **קריאת זנב אחת** (מסלול supersede/כפילות/פסול/אידמפוטנטיות מאותו snapshot; שורות ישנות מ-30 יום אינן רלוונטיות להגשה) · `countAttempts`: עמודות B,E,H של חי+ארכיון · append · `markPendingCompleted`. יעד: ≤ 7 RT, < 1.5MB.
- תשובה ל-404/HTML: הלקוח מסמן "לא ידוע" ושולח שוב; השרת אידמפוטנטי (session+id+ציון+זמן) — כמו היום.

### 3.4 סקר הנבחנים דרך Worker מאחד (`cloudflare-workers/session-gateway/`)

- `GET /v1/poll?kind=approval|status&sessionCode&idNumber&examineeToken` → **אותו JSON בדיוק** כמו `checkApproval`/`getExamStatus` היום (הלקוח מחליף כתובת, לא לוגיקה).
- upstream: `GET <API>?action=sessionSnapshot&sessionCode=X&gatewayKey=<secret>&origin=gateway` → `{status:'ok', at, rows:[{id, status, tokenHash, audio, examMinutes, extraMinutes}]}` (הטוקן לא עוזב את Apps Script; ה-Worker משווה SHA-256).
- איחוד: `caches.default` לפי סשן, TTL 3 שנ' + מפת in-flight בזיכרון → **הרצה אחת לסשן כל 3 שנ'** יהיו כמה נבחנים שיהיו. עותק "ישן" (60 שנ') מוגש עם `stale:true` כש-upstream נכשל.
- כשלים: upstream לא-JSON/HTTP-שגיאה → `{status:'error', code:'upstream_unavailable', retryable:true}` (HTTP 200) → הלקוח מאט (backoff) אבל **לא** נופל חזרה לישיר (אחרת הסערה חוזרת). נפילה לישיר רק כשה-Worker עצמו לא עונה (5xx/timeout/רשת) 3 פעמים רצופות, ל-5 דקות.
- מתג כיבוי בלי דחיפת Pages: `getSessionInfo` מחזיר `gateway:{url}` מ-ScriptProperty `GATEWAY_URL` (ריק = ישיר).
- תקציב חינם: 100k בקשות/יום לחשבון (משותף עם TTS/תמונות/דו"חות): 40 נבחנים × (12/דקה × 10 דק' המתנה + 7.5/דקה × 45 דק' מבחן) ≈ 18k לאתר-בוקר; שלושה אתרים ≈ 55k. מעל התקציב ה-Worker מחזיר 5xx → נפילה לישיר.
- CORS: מקור Pages בלבד. פריסה: `npx wrangler deploy` + `wrangler secret put GATEWAY_KEY` (יוסי).

### 3.6 לקוח

- **`shared/transport.js`** (נטען ב-4 הדפים + exam.html): `fetchJsonWithTimeout`, `noteTransport`/`isBackendDegraded` (כולל **2 timeouts רצופים = מדרדר**, S10), `pacePoll`/`jitterMs`, `apiGet`/`apiPost` עם `timeoutMs` תמיד, `withInFlightGuard` (D2), ריצת-לוג לקוח (50 אירועים אחרונים, ≤2KB, מצורף ל-POST הבא של הגשה/כשל). מורה ותלמיד: אין יותר `fetch` גולמי.
