## 4. Worker — session-gateway

במחשב, בתיקיית הריפו:
```bash

npx wrangler secret put GATEWAY_KEY
```
להדביק סוד ארוך אקראי (למשל 40 תווים; לשמור אותו — צריך אותו גם בצעד הבא), ואז:

## 5. Script Properties (בעורך Apps Script: הגדרות הפרויקט ← מאפייני סקריפט)

| מאפיין | ערך |
|---|---|
| `GATEWAY_KEY` | בדיוק אותו סוד מצעד 4 |
| `GATEWAY_URL` | הכתובת מצעד 4 (בלי `/` בסוף) |

**אימות:** `curl -s -L "<exec>?action=getSessionInfo&sessionCode=ZZZZZZ&origin=examinee-app"` → `{"status":"error","message":"קוד סשן לא תקין"}` (תקין: ה-handler רץ). ואז, עם סשן אמיתי של האתר `בדיקת נתונים` (צעד 7), דף הנבחן יקבל את כתובת ה-gateway — רואים בקונסולה `[POLL] gateway`.

**מתג כיבוי:** למחוק את `GATEWAY_URL` = כל הנבחנים חוזרים לסקר ישיר (בלי דחיפה).
