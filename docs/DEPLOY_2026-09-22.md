## 2. Worker — session-gateway (סקר + בנק)

```bash

```
נפתח דפדפן — לאשר. (נבדק 21/09 11:30: הטוקן השמור פג, לכן `login` הוא צעד חובה ולא "אם צריך".) אחר כך `npx wrangler whoami` מציג את חשבון ה-Cloudflare (אותו חשבון של `hebrew-tts`).

```bash

```
להדביק **סוד ארוך אקראי** (40+ תווים, למשל מ-`node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"`). **לשמור אותו — צריך אותו בצעד 3.** ואז:

```bash
npx wrangler deploy
```
ה-deploy מעלה גם את 1,700 קבצי הבנק (assets) ומדפיס כתובת — צפוי `https://session-gateway.bohanyzahal.workers.dev`.

**אימות:**
```bash

curl -s -o /dev/null -w '%{http_code}\n' "https://session-gateway.bohanyzahal.workers.dev/v1/bank?grant=bogus"
```
