# הדפים — מדריך לכל אפליקציה

ארבע אפליקציות עיקריות + שלוש משניות. כל אחת היא קובץ HTML בודד, self-contained, ללא build ו-ללא תלויות חיצוניות.

לכל דף: **מי המשתמש · המסכים · מה הוא קורא מה-API · איפה השמור מקומי · מלכודות**.

---

## 1. `examiner.html` — דף הבוחן

**המשתמש:** בוחן, לפעמים בוחן אחראי או מפקד. הדף הגדול ביותר (~468KB) והמורכב ביותר.

**התחברות:** ת.ז. + סיסמה מול גיליון `בוחנים` → טוקן עם תוקף. נעילה אחרי כשלונות חוזרים.

### מסכים ומצבים

| מצב | מה יש בו |
|---|---|
| פתיחת סשן | אתר, כיתה, דרגה, שפה, שמע (ברירת מחדל), אוכלוסייה, בוחן אחראי, מכסות |
| דשבורד חי | ממתינים לאישור · במבחן כרגע · שהסתיימו — פולינג כל 5 שניות |
| הכרעות פסילה | אישור/ביטול פסילה, כולל החזרת נבחן למבחן |
| דו"חות | דו"ח בוחן, דו"ח משותף לאתר, דו"ח מפקד |

### פעולות מרכזיות ב-API

`login` · `createSession` · `updateSession` · `closeSession` · `examinerDashboard` · `approveExaminee` · `rejectExaminee` · `disqualify` / `overturnDQ` / `confirmDQ` · `addExamTime` · `resetExaminee` · `forceComplete` · `correctToPass` · `submitManualResult` · `uploadResultHtml` · `commanderDashboard` · `examinerForecast`

### תפקידים

`בוחן` רגיל · `רב בוחן` · `מפקד` / `מפקד מקומי` / `מפקד מרכז` / `מפקד ראשי` · `אדמין`. תפקידי מפקד פותחים דשבורד רוחבי; דו"ח משותף לאתר דורש בוחן אחראי או מפקד.

### מלכודות

- **`updateSession` מוגבל לבעלים** — רק הבוחן שפתח את הסשן יכול לעדכן. בוחן שני יקבל "אין הרשאה".
- **הדשבורד מרנדר מחדש כל 5 שניות** מנתוני שרת. כל בחירה בממשק שטרם נשמרה בשרת נמחקת — חייבים מפת override לפי ת.ז. (קיים ל: הארכת זמן, שמע, תיקון טלפון). **זו הייתה תקלת השמע ב-28/07.**
- **סגירת סשן חסומה** עד שיתוף דו"ח, אם יש תוצאות.
- הדף מציג באנר עדכון עם שהות 60 שניות — **בטוח לדחוף בכל שעה**.

## 2. `examinee.html` — דף הנבחן

**המשתמש:** נבחן. הדף הרגיש ביותר — כאן קורה המבחן עצמו.

**זיהוי:** אין סיסמה. קוד סשן → פרטים אישיים → טוקן נבחן מהשרת, שנדרש בכל קריאה עוקבת.

### מסכים

`screenCode` → `screenIdForm` → `screenInstructions` (המתנה + הנחיות) → `screenExam` → `screenDone`

### פעולות ב-API

`getSessionInfo` · `registerExaminee` · `cancelRegistration` · `checkApproval` (פולינג 5 שניות) · `getExamQuestions` · `registerExamQuestions` · `markExamStarted` · `markFinished` · `submitResult` (POST) · `submitWrongAnswers` · `disqualify` / `reportWarning` · `submitFailOnClose` / `cancelFailOnClose` · `getQuestionsByIds` (החלפת שפה תוך כדי)

### שמור מקומי

| מפתח | תפקיד |
|---|---|
| `ext_examinee_state` | מסך נוכחי + נתוני סשן ונבחן (localStorage + sessionStorage) |
| `ext_exam_active` | מבחן פעיל לשחזור אחרי רענון |
| `pendingResult_<ת.ז.>` | תוצאה שטרם אושרה בשרת — **נשלחת מחדש בטעינת דף** |
| `examEnded_*`, `examSuspended_*` | סמני סיום/השהיה |

### מנגנוני יושרה

זיהוי מעבר לשונית · אכיפת מסך מלא · זיהוי מסך מפוצל · זיהוי מסך חיצוני · מלכודת devtools · חסימת כפתור אחורה · חסימת העתקה/הדבקה/תפריט הקשר · כישלון-בסגירה דרך `sendBeacon`.

### מלכודות

- **המבחן רץ מקומית לחלוטין.** רשת נדרשת רק בתחילה ובהגשה. אל "תשפר" את זה — זו עמידות מכוונת.
- **אסור `confirm()`/`alert()`** בשום זרימה קריטית — ב-iOS זה מפעיל blur (פסילת שווא) ומדוכא תחת `beforeunload`. מודאל בתוך הדף בלבד.
- **אסור לדחוף בשעות בחינות** — רענון עצמי תוך 2 דקות.
- תוצאה לעולם לא נמחקת מקומית לפני אישור שרת — כך "תוצאות שנעלמו" נמצאות.

## 3. `teacher.html` — דף המורה

**המשתמש:** מורה, ובתפקיד מפקד — גם דשבורד רוחבי על כל הכיתות.

**התחברות:** ת.ז. + סיסמה מול גיליון `מורים` → טוקן עם תוקף.

### מסכים

| מסך | מה יש בו |
|---|---|
| `screenLogin` | התחברות |
| `screenDashboard` | רשימת הכיתות של המורה + יצירת כיתה |
| `screenClassDetail` | תלמידי הכיתה, ביצועי תרגול, הסרת תלמיד |
| `screenStudentDetail` | פירוט תלמיד יחיד: היסטוריה, נושאים חלשים |
| `screenCommander` | **תצוגת מפקד** — חתך על כל הכיתות, נבחנים בסיכון, פילוח לפי מורה/אתר |

### פעולות ב-API

`teacherLogin` · `teacherVerifyLogin` · `teacherGetClasses` · `teacherCreateClass` · `teacherClassDetails` · `teacherCloseClass` · `teacherDeleteClass` · `teacherRemoveStudent` · `teacherExportData` · `teacherCommanderDashboard` · `teacherAtRiskList`

### מה מזין את התצוגות

הכל מגיליון `תוצאות תרגול` — **לא** מ`תוצאות` של המבחנים האמיתיים. שים לב שהמבנה שונה: פירוט השגויות הוא **JSON** (`{qNum, category, qText}`), הזמן בפורמט `M:SS`, והתאריך `DD/MM/YYYY HH:mm`.

תצוגת המפקד מוסיפה: ממוצע וחציון זמן, עשר השאלות הכושלות ביותר, ופילוח פעילות לפי שעה.

### מלכודות

- **יצירת כיתה מוגנת בסיסמה/טוקן** — אין עקיפה.
- **מחיקת כיתה מוחקת את שורת הכיתה ומשאירה את תוצאות התרגול יתומות.** לכן קיים גיליון `כיתות שנמחקו` שמשחזר את שם המורה בדו"ח. **רק מחיקות שבוצעו אחרי הוספת המנגנון מתועדות** — יתומים היסטוריים יציגו "לא ידוע".
- `handleSubmitPracticeResult` **אינו מאמת קוד כיתה** — כל קוד מתקבל. פריט פתוח ב-`TODO.md`.
- בטוח לדחוף בכל שעה (באנר + שהות).

## 4. `student.html` — דף התלמיד

**המשתמש:** תלמיד שמתרגל. אין סיסמה.

**זיהוי:** הצטרפות לכיתה עם קוד כיתה + שם (`studentJoinClass`). **תרגול אנונימי אפשרי** — ללא קוד כיתה, ואז `studentId=anon` והתוצאות לא משויכות למורה.

### מסכים ומצבי תרגול

| מסך | מצב |
|---|---|
| `screenWelcome` | הצטרפות לכיתה / כניסה אנונימית |
| `screenModeSelect` | בחירת מצב תרגול |
| `screenPractice` | מבחן מלא / תרגול לפי נושא |
| `screenFlashcards` | כרטיסיות |
| `screenResults` | תוצאות ופירוט |
| `screenHistory` | היסטוריית תרגולים |
| `screenTips` | טיפים |

**ארבעה מצבי תרגול:**

| מצב | איך נטענות השאלות |
|---|---|
| מבחן מלא | `getExamQuestions` עם `mode=exam` |
| תרגול לפי נושא | `getExamQuestions` עם `mode=category`, עד 15 שאלות |
| כרטיסיות | `getExamQuestions` דרך `_fetchServerQuestions` |
| חזרה על שגיאות | `getQuestionsByIds` — מזהי השאלות השגויות מ-`localStorage`, עד 15 |

### פעולות ב-API

`studentJoinClass` · `getExamQuestions` · `getQuestionsByIds` · `submitPracticeResult` (POST) · `loadStudentProgress` · `saveStudentProgress` (POST)

### שמור מקומי

`student_wrong_qs` — שאלות שנענו שגוי, הבסיס לחזרה המרווחת. מסונכרן גם לגיליון `התקדמות תלמידים` (streak, היסטוריה).

### מלכודות

- **התרגול חולק את אותו טוען שאלות, מטמון וחוטי ביצוע עם המבחנים.** גל תרגול משפיע על בחינות חיות — זה מה שהפך את שיא ה-13:00 לתקלה.
- הדף מרענן את עצמו בשקט כמו דף הנבחן. **מגן הרענון שנוסף ל-`examinee.html` טרם הוחל כאן** — פריט פתוח.
- `buildFlashcardSet` (שורה ~1093) ו-`getFilteredQuestions` (שורה ~669) הם **קוד מת** — שריד מהתקופה שבה הסינון היה מקומי. הכרטיסיות עברו לשרת. אפשר למחוק.
- **נפרד ממערכת הבחינות** — בטוח יחסית לפרוס אותו גם ביום בחינות, אך לא באמצע תרגול כיתתי.

## 6. מה משותף לכל הדפים

- **`API_URL`** — כתובת ה-`/exec`. קיימת בכל דף בנפרד. החלפת deployment דורשת עדכון **בכל הדפים** (וזכור ש-`report.html` שונה).
- **`API_ORIGIN`** — מזהה מתוך ה-allowlist (`examiner-app`, `examinee-app`, `teacher-app`, `student-app`). חסר → השרת דוחה.
- **תבנית IIFE** — `(function() { 'use strict'; ... })()`.
- **RTL עברית** עם מעבר לשפות אחרות בדפי הנבחן.
- **עדכון עצמי** — בדיקת ETag כל 2 דקות. שקט בדפי נבחן/תלמיד, באנר בדפי בוחן/מורה.
- **service worker** לכל אפליקציה, network-first, + קליפת PWA ב-iframe.
